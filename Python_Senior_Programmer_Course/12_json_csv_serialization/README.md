# JSON, CSV & Serialization

This module is part of the Senior Python Programmer course.

## Learning objectives
- Understand the core concept.
- Run every example.
- Modify the examples and observe the behavior.
- Apply the concept in automation and production code.

## Practice
For each example:
1. Run it.
2. Predict the output before running.
3. Change one thing.
4. Add a test.
5. Refactor it using clean-code principles.
