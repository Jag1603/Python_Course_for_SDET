# Senior Python Programmer — Suggested 12-Week Plan

## Week 1
Basics, variables, strings, collections, control flow.

## Week 2
Functions, functional programming, modules/packages.

## Week 3
OOP, advanced OOP, exceptions.

## Week 4
Files, JSON/CSV, dates, iterators/generators.

## Week 5
Decorators, context managers, regex, typing, dataclasses.

## Week 6
Logging, configuration, pytest, fixtures, mocking.

## Week 7
Async programming, threading, multiprocessing.

## Week 8
HTTP, REST APIs, API clients, SQL and SQLite.

## Week 9
Performance, profiling, security, CLI development.

## Week 10
Packaging, design patterns, SOLID, clean code.

## Week 11
Algorithms, Python internals, automation.

## Week 12
FastAPI, SDET architecture, CI/CD, capstone.

## Senior checklist
- [ ] Explain mutability and object identity.
- [ ] Explain `is` vs `==`.
- [ ] Use comprehensions appropriately.
- [ ] Design classes using composition where appropriate.
- [ ] Build reusable decorators/context managers.
- [ ] Type public APIs.
- [ ] Write pytest fixtures and parametrized tests.
- [ ] Mock external dependencies without over-mocking.
- [ ] Know when to use async vs threads vs processes.
- [ ] Build a robust REST client.
- [ ] Use parameterized SQL.
- [ ] Profile before optimizing.
- [ ] Secure secrets and untrusted input.
- [ ] Package a Python project.
- [ ] Apply SOLID and design patterns pragmatically.
- [ ] Build CI/CD quality gates.
