# Python Senior Programmer — Complete Course

A practical, example-first Python course designed for a Senior SDET / Senior Python Programmer.

## How to use
1. Install Python 3.12+.
2. Open this folder in VS Code/PyCharm.
3. Start with `00_setup_and_python_basics`.
4. Run examples with:
   `python path/to/example.py`
5. Each topic contains a `README.md`, runnable examples, and exercises where appropriate.

## Senior-level goals
- Write maintainable, testable Python.
- Use OOP, functional patterns, typing, async, concurrency and design patterns appropriately.
- Build REST clients, database layers and CLI tools.
- Write production-grade tests with pytest and mocks.
- Understand packaging, logging, configuration and security.
- Build automation frameworks using clean architecture.
